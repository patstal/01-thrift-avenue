# 01 Thrift Avenue

**Original sustainable-fashion business concept, designed and developed as a responsive website prototype.**

01 Thrift Avenue was a project I developed during my MSc in Digital Economy at King’s College London. I created the original business idea, developed and pitched the concept, designed the interface in Figma, and then built the responsive multi-page website prototype using HTML, CSS and JavaScript.

The concept explored how independent second-hand shops could gain greater online visibility while encouraging more sustainable fashion consumption. The project received a Distinction.

## From concept to prototype

For this project, I:

- developed the original business concept and value proposition
- created and presented the project pitch
- designed the website structure and interface in Figma
- built the prototype using HTML, CSS and JavaScript
- created responsive layouts for desktop, tablet and mobile use
- implemented a responsive navigation menu and image slideshow
- built linked pages for thrift shops, clothing listings and individual items
- gathered user feedback and incorporated it into the design
- tested the prototype across different browsers and device sizes

- `mystyle.css` – site styling and responsive layouts
- `javascript/script.js` – navigation and slideshow behaviour

## Academic context

This was an MSc student project rather than a production website. It was intended to take an original business idea from concept and pitch through visual design to a working web prototype.

For presentation in this repository, I only corrected obvious syntax issues, broken declarations, spelling errors and a JavaScript error that affected pages without a slideshow. No new features were added, and the original structure, design and functionality were kept substantially unchanged.

Parts of the responsive navigation and slideshow were developed with reference to tutorials that are acknowledged in the source-code comments.
